# Fast Printer

Drag-and-drop PDF printing for TSPL thermal label printers on Windows.

<!-- screenshot -->

Fast Printer is a tiny Windows desktop app for thermal label printers. Drag a PDF in (or click to browse), pick a label size, and click Print. It renders each page to a crisp 1-bit image at 203 dpi and sends TSPL commands RAW straight to the printer, so speed, darkness and copies come from the app rather than the Windows driver.

## Features

- Drag and drop PDFs, or click to browse
- Multi-page PDFs: one label per page, auto-rotated and centred to fit
- Printer dropdown listing every printer installed for the current Windows user (refreshes when opened)
- Built-in 100 x 150 mm (4x6 shipping) and 60 x 30 mm label sizes
- Custom label sizes: add or remove them via "Label sizes" in the header
- Per-size speed, darkness and copies, remembered between sessions
- Fixed 3 mm label gap

## Supported printers

The printer must understand TSPL. That includes Munbyn and many TSC, Xprinter, HPRT and iDPRT-style 4x6 thermal printers.

Zebra printers that only speak ZPL, and normal office printers, will not work.

Tested on a Munbyn ITPP130. Runs on Windows 10 and 11.

## Download

Get `Fast Printer.exe` from the [Releases page](https://github.com/Gromit1999/fast-printer/releases). No install needed, just run it.

## Usage

1. Open Fast Printer.
2. Pick your thermal printer from the dropdown.
3. Pick a label size (or add your own under "Label sizes").
4. Drag a PDF onto the window, or click to browse.
5. Adjust speed, darkness and copies if needed, then click Print.

## Run from source

```
pip install -r requirements.txt
python "Fast Printer.py"
```

Dependencies: pymupdf, pywin32, pillow, tkinterdnd2.

## Build the .exe

The app is packaged with PyInstaller as a single windowed file:

```
pyinstaller --onefile --windowed --name "Fast Printer" --collect-all tkinterdnd2 --icon fastprinter.ico "Fast Printer.py"
```

The icon is generated by the app itself. Create it first with:

```
python "Fast Printer.py" --write-icon fastprinter.ico
```

The finished exe is written to `dist/`.

## Settings

Settings (including per-size speed, darkness and copies, and your custom label sizes) are stored in:

```
%APPDATA%\FastPrinter\settings.json
```
